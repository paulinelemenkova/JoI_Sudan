# Multispectral Satellite Image Analysis for Computing Vegetation Indices by R in the Khartoum Region of Sudan, Northeast Africa

LaTeX source for the peer-reviewed article by Polina Lemenkova and Olivier Debeir.

**Published in:** *Journal of Imaging* **2023**, *9*(5), 98
**DOI:** https://doi.org/10.3390/jimaging9050098

The R scripts used to compute and plot the vegetation indices are in a separate repository cited in the paper: https://github.com/paulinelemenkova/Mapping_Sudan_Scripts

## Citation
Lemenkova, P.; Debeir, O. Multispectral Satellite Image Analysis for Computing Vegetation Indices by R in the Khartoum Region of Sudan, Northeast Africa. *Journal of Imaging* **2023**, *9*, 98. https://doi.org/10.3390/jimaging9050098
